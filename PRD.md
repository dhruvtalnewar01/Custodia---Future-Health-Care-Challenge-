## 1. PROBLEM STATEMENT & GLOBAL VALUE PROPOSITION
Across global health systems (US IDNs, UK NHS Trusts, India ABDM, and UAE DoH/Malaffi), published clinical studies show that 7% to 62% of actionable abnormal outpatient screening results fail to convert into timely confirmatory diagnostics and documented treatment initiation. Four structural failures cause this drop-off:
1. **Custody Evaporation:** Transmitting a lab flag or specialist referral relinquishes responsibility into an inter-organizational void with no single accountable owner.
2. **Patient Anxiety & Comprehension Failure:** Generic SMS notifications ("Abnormal result detected") trigger panic, cultural stigma, or confusion between a proactive screening flag and a definitive medical diagnosis.
3. **Specialist Referral Bounce:** Referrals across facilities are rejected weeks later because the referring primary care physician (PCP) omitted mandatory prerequisite confirmatory tests.
4. **Administrative False Closure:** EHR workflows mark cases "Closed" when a letter is printed or an appointment is requested, without verifying that clinical care actually occurred.

**CUSTODIA** converts every actionable screening result into a **Self-Enforcing Clinical Custody Contract** governed by a deterministic 8-state machine, a Two-Phase Custody Handshake, Pre-Flight Referral Validation, multilingual Teach-Back verification, and Dual-Key Cryptographic Proof-of-Closure.

## 2. HARDENED ARCHITECTURAL INVARIANTS
1. **Neuro-Symbolic Separation (Zero LLM in Acuity or Closure):** OpenAI models (`gpt-4o`, `gpt-4o-mini`, `whisper-1`, `tts-1`, `omni-moderation-latest`) are restricted to structured data extraction, citation-grounded synthesis, multilingual translation, and conversational Teach-Back evaluation. Acuity tiers, SLA deadlines, prerequisite test checks, and closure permissions are computed 100% deterministically by `/backend/engine/rules_engine.py`.
2. **Idempotency & Amended Report Guard:** Incoming reports are deduplicated on `(patient_id, accession_number, finding_category)`. If an amended report (`status = amended`) arrives for an open loop, CUSTODIA updates the existing loop in-place and records an `AMENDED_REPORT_MERGED` audit block rather than spawning a duplicate case. If a lab cancels an artifact (`status = cancelled`), the loop transitions safely via an audited exception path.
3. **Two-Phase Custody Handshake with Optimistic Locking:** During cross-provider referrals, `custody_holder_id` remains locked with the originating clinician (`handshake_status = PENDING_ACCEPTANCE`) until the receiving specialist signs `Task.status = accepted` with a confirmed slot. Rejected or SLA-expired referrals automatically reroute to an alternate network facility. All updates check `optimistic_version` to prevent race conditions.
4. **Post-Generation FHIR Citation Verifier:** Every clinical claim generated by `gpt-4o` on the 90-second Specialist e-Consult Card must cite a `fhir_resource_id`. A deterministic Python post-processor checks every cited ID against the patient's stored `fhir_resources` rows and marks `citation_verified = True/False`.
5. **Dual-Key Proof-of-Closure (PoC) with Real ECDSA / WebAuthn Cryptography:** Transitioning to `8_VERIFIED_CLOSED` requires:
   - **Key 1 (Machine-Verified FHIR R4 Artifact):** A stored confirmatory `DiagnosticReport`, active `CarePlan`/`MedicationRequest`, or co-signed informed refusal `Consent` resource.
   - **Key 2 (Cryptographic Clinician Signature):** A verified WebAuthn Passkey assertion or browser-generated `ECDSA P-256` (`SHA-256`) digital signature verified on the backend against the clinician's exported public key (`JWK`).
6. **RFC 8785 Canonical SHA-256 Audit Chain:** Every state transition writes an append-only row to `custody_audit_log` where:
   `curr_hash = SHA256(f"{prev_hash}|{loop_id}|{seq_num}|{from_state}|{to_state}|{actor_id}|{created_at_ms}|{canonical_json(payload)}")`.

## 3. CROSS-DIALECT DATABASE SCHEMA (SQLALCHEMY 2.0 : SUPABASE POSTGRESQL + ZERO-CONFIG SQLITE)
Implement in `/backend/models.py` using SQLAlchemy 2.0 `DeclarativeBase` so it runs identically on PostgreSQL (`DATABASE_URL=postgresql+asyncpg://...`) and local SQLite (`DATABASE_URL=sqlite+aiosqlite:///./custodia.db`):

```python
import uuid
from datetime import datetime, timezone
from sqlalchemy import String, Integer, Float, Boolean, Text, ForeignKey, JSON
from sqlalchemy.dialects.postgresql import JSONB
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

JSONVariant = JSON().with_variant(JSONB, "postgresql")

class Base(DeclarativeBase):
    pass

class PatientModel(Base):
    __tablename__ = "patients"
    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
    mrn: Mapped[str] = mapped_column(String(64), unique=True, index=True)
    full_name: Mapped[str] = mapped_column(String(120))
    age: Mapped[int] = mapped_column(Integer)
    sex: Mapped[str] = mapped_column(String(16))
    preferred_language: Mapped[str] = mapped_column(String(32), default="en")
    region_code: Mapped[str] = mapped_column(String(64))
    nationality_group: Mapped[str] = mapped_column(String(64), default="Local Cohort")
    payer_plan: Mapped[str] = mapped_column(String(64))
    distance_km: Mapped[float] = mapped_column(Float, default=8.5)
    prior_no_show_count: Mapped[int] = mapped_column(Integer, default=0)
    fhir_patient_json: Mapped[dict] = mapped_column(JSONVariant)
    created_at_iso: Mapped[str] = mapped_column(String(40), default=lambda: datetime.now(timezone.utc).isoformat())

class FhirResourceModel(Base):
    __tablename__ = "fhir_resources"
    id: Mapped[str] = mapped_column(String(96), primary_key=True)
    patient_id: Mapped[str] = mapped_column(String(36), ForeignKey("patients.id", ondelete="CASCADE"), index=True)
    accession_number: Mapped[str] = mapped_column(String(64), index=True)
    resource_type: Mapped[str] = mapped_column(String(48)) # DiagnosticReport, Observation, Task, ServiceRequest, CarePlan, MedicationRequest, Consent
    loinc_or_icd_code: Mapped[str] = mapped_column(String(48), nullable=True)
    report_status: Mapped[str] = mapped_column(String(32), default="final") # final, amended, cancelled
    display_summary: Mapped[str] = mapped_column(Text)
    numeric_value: Mapped[float] = mapped_column(Float, nullable=True)
    unit: Mapped[str] = mapped_column(String(32), nullable=True)
    fhir_json: Mapped[dict] = mapped_column(JSONVariant)
    extraction_confidence: Mapped[float] = mapped_column(Float, default=1.0)
    source_text_span: Mapped[str] = mapped_column(Text, nullable=True)
    created_at_iso: Mapped[str] = mapped_column(String(40), default=lambda: datetime.now(timezone.utc).isoformat())

class ScreeningLoopModel(Base):
    __tablename__ = "screening_loops"
    id: Mapped[str] = mapped_column(String(36), primary_key=True, default=lambda: str(uuid.uuid4()))
    loop_code: Mapped[str] = mapped_column(String(32), unique=True, index=True)
    patient_id: Mapped[str] = mapped_column(String(36), ForeignKey("patients.id", ondelete="CASCADE"), index=True)
    market_pack_id: Mapped[str] = mapped_column(String(48), default="pack-uae-doh", index=True)
    trigger_resource_id: Mapped[str] = mapped_column(String(96), ForeignKey("fhir_resources.id"))
    accession_number: Mapped[str] = mapped_column(String(64), index=True)
    finding_category: Mapped[str] = mapped_column(String(64)) # BREAST_BIRADS_4, METABOLIC_HBA1C_RENAL, COLORECTAL_FIT_POS, ELECTROLYTE_CRITICAL, GENOMIC_COUPLE_HBB, UROLOGY_PSA_ELEVATED
    acuity_tier: Mapped[str] = mapped_column(String(24)) # TIER_1_CRITICAL, TIER_2_HIGH, TIER_3_ROUTINE
    current_state: Mapped[str] = mapped_column(String(48), default="1_RESULT_ISSUED")
    optimistic_version: Mapped[int] = mapped_column(Integer, default=1)
    custody_holder_id: Mapped[str] = mapped_column(String(96))
    custody_holder_name: Mapped[str] = mapped_column(String(120))
    custody_facility: Mapped[str] = mapped_column(String(120))
    target_specialty: Mapped[str] = mapped_column(String(80))
    receiving_specialist_facility: Mapped[str] = mapped_column(String(120), nullable=True)
    handshake_status: Mapped[str] = mapped_column(String(32), default="ORIGIN_HELD") # ORIGIN_HELD, PENDING_ACCEPTANCE, ACCEPTED_TRANSFERRED, REJECTED_REROUTED
    sla_hours: Mapped[int] = mapped_column(Integer)
    sla_deadline_iso: Mapped[str] = mapped_column(String(40))
    sla_breached: Mapped[bool] = mapped_column(Boolean, default=False)
    comprehension_score: Mapped[int] = mapped_column(Integer, default=0)
    teachback_turns: Mapped[list] = mapped_column(JSONVariant, default=list)
    dropoff_hazard_score: Mapped[float] = mapped_column(Float, default=0.15)
    dropoff_top_factors: Mapped[list] = mapped_column(JSONVariant, default=list)
    recommended_friction_breaker: Mapped[str] = mapped_column(String(160), nullable=True)
    prereq_validation_passed: Mapped[bool] = mapped_column(Boolean, default=False)
    missing_prereq_Leading_items: Mapped[list] = mapped_column("missing_prereq_items", JSONVariant, default=list)
    econsult_card_json: Mapped[dict] = mapped_column(JSONVariant, nullable=True)
    booked_slot_json: Mapped[dict] = mapped_column(JSONVariant, nullable=True)
    closure_code: Mapped[str] = mapped_column(String(48), nullable=True)
    closure_fhir_evidence_id: Mapped[str] = mapped_column(String(96), nullable=True)
    closure_clinician_signature: Mapped[str] = mapped_column(Text, nullable=True)
    closure_public_key_jwk: Mapped[dict] = mapped_column(JSONVariant, nullable=True)
    closed_at_iso: Mapped[str] = mapped_column(String(40), nullable=True)
    created_at_iso: Mapped[str] = mapped_column(String(40), default=lambda: datetime.now(timezone.utc).isoformat())
    updated_at_iso: Mapped[str] = mapped_column(String(40), default=lambda: datetime.now(timezone.utc).isoformat())

class CustodyAuditLogModel(Base):
    __tablename__ = "custody_audit_log"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    loop_id: Mapped[str] = mapped_column(String(36), ForeignKey("screening_loops.id", ondelete="CASCADE"), index=True)
    seq_num: Mapped[int] = mapped_column(Integer)
    from_state: Mapped[str] = mapped_column(String(48), nullable=True)
    to_state: Mapped[str] = mapped_column(String(48))
    actor_id: Mapped[str] = mapped_column(String(96))
    actor_role: Mapped[str] = mapped_column(String(48))
    event_type: Mapped[str] = mapped_column(String(64))
    payload_json: Mapped[dict] = mapped_column(JSONVariant)
    created_at_ms: Mapped[int] = mapped_column(Integer)
    prev_hash: Mapped[str] = mapped_column(String(64))
    curr_hash: Mapped[str] = mapped_column(String(64))
